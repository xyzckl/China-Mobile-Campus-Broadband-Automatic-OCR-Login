# China Mobile Campus Broadband Auto OCR Login

这是一个为中国移动校园宽带认证页面自动识别验证码并登录的 Tampermonkey 用户脚本。

## 功能
- 自动识别验证码（集成 Tesseract.js）
- 登录失败自动重试（可开关）
- 自定义背景/高级主题支持
- 本地图片和网络图片背景模式
- 高级主题 JSON 校验与缓存
- 用户界面基于 Material You 风格

## 安装
1. 安装 Tampermonkey（Chrome/Firefox）
2. 通过GitHub释放获取脚本，也可以访问网站下载门户https://cmcnauto.xyzckl.site
3. 在 Tampermonkey 中启用脚本

## 配置
- 脚本面板按钮：页面右上角工具按钮
- 高级主题: 打开后可指定本地或网络主题JSON
- 本地/网络背景: 可切换并保存选项
